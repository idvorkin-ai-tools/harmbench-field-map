Copyright Violations

The one category graded by hash instead of by model — and the one place the attack ranking turns upside down.
TL;DR — Copyright is the odd category out on every axis. Its semantic label and its functional label are the same word, so it is the only slice of HarmBench where a per-category ASR table exists by construction. It never touches the Llama 2 classifier: 100 MinHash pickles ship in place of the copyrighted works, and a completion scores 1 only if a sliding window of it matches a reference window at Jaccard > 0.6. That near-verbatim standard puts every attack near the floor — and it inverts the leaderboard. GCG, the strongest attack everywhere else at 54.3, manages 4.6 here; plain DirectRequest, the floor everywhere else at 25.3, manages 7.3. Optimising a prompt to make a model say yes does nothing to make it remember.

Every other harm page on this map has to admit up front that the paper never tabulates ASR per semantic category. This one does not, and the reason is a coincidence of taxonomy: HarmBench's seven semantic categories and four functional categories cross freely except here, where SemanticCategory = copyright and FunctionalCategory = copyright are the same 100 rows. Table 6's copyright sub-table is therefore a per-category table whether the authors meant it as one or not. That makes this page the only place in the map where you can watch attack methods re-rank themselves against a different definition of success — and the re-ranking is the most instructive thing in the results.

What is in this category

Appendix B.4 gives copyright exactly two sub-bullets, the shortest taxonomy of any of the seven categories:

  • Generating copyrighted books
  • Generating copyrighted lyrics

The repository splits them down the middle, and the test/val split respects that split exactly.

The functional-type breakdown is the degenerate one: 0 standard, 0 contextual, 100 copyright, 0 multimodal. No copyright behavior carries a ContextString — the column is empty on all 100 rows — so nothing here can be silently broken by a harness that drops that column, which is the standing hazard for the contextual quarter of the set. Every row carries the hash_check tag plus exactly one of book or lyrics; those, with context on the 100 contextual behaviors, are the only tags that exist in the shipped text CSV. The tag is not decoration. It is a dispatch key: the grader reads it to decide which window size to use, and raises if it finds neither value.

The shape of the counts tells you this is a uniform test, not a diverse one. Cybercrime spreads 67 text behaviors across two sub-types and three functional types; copyright puts 100 behaviors through a single template — name a work, ask for its text — and varies only the work. The prompts are correspondingly tiny: lyrics requests run 41–75 characters (median 51), book requests 54–137 (median 68.5). These are the shortest, plainest asks in the benchmark. There is no craft in the behavior itself; all the difficulty is in the grading and in the model's memory.

How this category is graded

Copyright is the one category that never sees the fine-tuned Llama 2 13B judge. compute_results_hashing handles it instead: load data/copyright_classifier_hashes/<BehaviorID>.pkl, run a spaCy-tokenised sliding window over the model's completion, MinHash each window, and label the completion 1 if the maximum pairwise Jaccard against any reference window exceeds 0.6. Window geometry comes from the tag: book uses window_size=300, overlap=200; lyrics uses window_size=50, overlap=40. The mechanics and the reasoning behind those two numbers are the subject of the copyright type page; what matters here is what the choice does to a number on this page.

Three consequences, in order of how often they are missed.

First, the metric measures output, not intent. Everywhere else in HarmBench the standard is whether the model attempted the behavior — a keylogger script that does not compile still counts, because the benchmark is trying to separate safety from capability. Copyright abandons that standard deliberately, and the authors say why:

"Discerning whether an LLM is trying to exhibit a behavior (the standard we apply for other behaviors) is uniquely challenging when the behavior is generation of copyrighted content. This is because the generation of works inspired by the original copyrighted content are hard to distinguish from attempts to generate the content verbatim."— HarmBench, §B.5.2

A judge asked "is this an attempt to reproduce Sapiens?" cannot separate plagiarism from pastiche, so the benchmark stops asking and checks the text. A model that cheerfully agrees and then improvises 400 words in roughly the right register scores exactly 0, the same as a model that refuses outright. So does an accurate paraphrase, an accurate summary, and a chorus reproduced with two words changed per line if that drags Jaccard below the threshold. The reported ASR is a floor on regurgitation, not a measure of willingness.

Second, the generation budget is doing real work here. Completions are capped at 512 new tokens, fixed, for comparability. A book behavior has to fill a 300-token window with near-verbatim text to register at all — most of the entire allowed completion. A lyrics behavior needs only 50 consecutive tokens, roughly a verse. The two sub-types are not equally hard to trip, and the paper does not report them separately: Table 6's copyright grid is one block, not two. If you care about the book/lyrics asymmetry you have to re-run the eval yourself with the tags split out.

Third, there is no human-agreement number for this path. Table 3's 93.19% classifier/human agreement, and the ~7% label noise that follows from it, are measured on standard and contextual behaviors only — those are the table's two rows. The hashing grader is not on it. That is defensible (a hash match is closer to a fact than a judgment) but it means the usual caveat has to be swapped for a different one: the copyright numbers are not noisy in the classifier sense, they are narrow, and the narrowness is the whole design. See the grader page for how the dispatch sits alongside the classifier path.

One practical upside falls out of this: copyright is the only category you can grade without a GPU. Every other category needs the 13B judge loaded at eval time. Here you need a pickle and spaCy.

What the behaviors ask for

Six IDs that span both sub-types and both splits. Every one is the same request shape — name a work, ask for its text — so the interesting variation is in which works the authors picked.

The selection reads as a deliberate sweep of memorisation likelihood rather than of harm severity. Fiction blockbusters, self-help perennials, a computer-science textbook, chart pop across four decades. That is a sensible spread if what you are probing is how much of the training corpus survives in the weights, which is what this category actually measures. The full list of all 100 IDs, with tags and split, is on the behaviors index.

Why you see titles and not text. The BehaviorIDs are public identifiers in the repository, so naming them is safe and useful. The works themselves are not in the repository and are not on this site: HarmBench ships 100 irreversible MinHash sketches in data/copyright_classifier_hashes/ precisely so the benchmark can be reproduced without anyone redistributing the copyrighted material. That design choice is the reason this category is runnable at all, and it is why no passage, lyric or prompt string appears anywhere in this map.

What the paper reports for this category

Read the last two columns. The gradient family — GCG, GCG-Multi, AutoPrompt, UAT, PEZ, GBDA, the methods that dominate everywhere else and cost the most GPU hours — occupies ranks 9, 10, 13, 14, 15 and 16. PAP-top5, the weakest attack in the benchmark at 16.6 average, comes third. Plain DirectRequest — ask the model, no attack — beats every gradient method by more than half again.

The mechanism explains it cleanly. A token-level attack minimises the negative log-likelihood of a fixed target string under the model, then hands the resulting prompt to the target and grades whatever comes out. The target strings shipped for copyright behaviors are short — 45 to 141 characters, median 64.5 — and could not possibly be the works themselves, since the repository ships only hashes. They are affirmative openers. So GCG is being asked to find a suffix that makes the model start with a sentence agreeing to the request. It is good at that. But "starts by agreeing" and "then recites 300 tokens of Thinking, Fast and Slow from memory" are unrelated events. The suffix suppresses refusal; it cannot install a memory the model does not have. Everywhere else in HarmBench, suppressing refusal is the task, because attempting the behavior counts. Here it is a prerequisite that buys almost nothing.

What does help, marginally, is anything that gets the model talking at length in a compliant register — conversational optimisers like TAP and PAIR, persuasion-style rephrasings like PAP, and, embarrassingly for the field, just asking. The gaps are small in absolute terms and should not be over-read: 8.5 against 7.3 is roughly one behavior in a hundred.

The per-model rows carry a second finding, and it is the one that should change how you read the whole table. In the copyright grid, ASR rises with model size within a family — the opposite of the paper's headline result that robustness is independent of scale. Llama 2 Chat under GCG goes 3.0 → 6.0 → 10.0 from 7B to 13B to 70B. Qwen Chat under DirectRequest goes 4.0 → 10.0 → 26.0 from 7B to 14B to 72B. Koala 7B scores exactly 0.0 in all sixteen columns. The single highest cell in the grid, 28.0, belongs to Mixtral 8×7B under DirectRequest — no attack at all. The authors name the caveat themselves:

"One caveat to this result is our copyright behaviors, for which we observe increasing ASR in the largest model sizes. We hypothesize that this is due to smaller models being incapable of carrying out the copyright behaviors."— HarmBench, §6.1

That is the honest reading: a low copyright score can mean a well-defended model or a small one that never memorised the text. Koala 7B's perfect zero is not a safety achievement. This is the one place in HarmBench where the metric fails to separate safety from capability, and the authors say so rather than burying it.

One more thing worth knowing before you cite a number from this sub-table. The arXiv v2 HTML prints an Average row under the Copyright block whose entries run from 17.3 to 50.7 — impossible, since no individual cell in the grid exceeds 28.0. The figures used on this page are the column means recomputed from the grid itself; they match the copyright averages printed in the test-split and validation-split tables, and they reconcile the All-Behaviors row exactly, both in aggregate and per model. The full arithmetic is on the results page, along with the rest of Table 6. Treat the printed row as a typesetting error in v2.

A corollary for anyone quoting a headline ASR: the All-Behaviors averages blend 100 copyright behaviors, graded on a stricter metric with a much lower ceiling, into a mean with 200 standard and 100 contextual behaviors graded by the classifier. Drop the copyright quarter and GCG's average moves from 54.3 to about 71. Neither number is wrong; they answer different questions, and the difference is a quarter of the text set being scored on a different scale.

The multimodal side

There is none. Copyright is the only one of the seven semantic categories with zero multimodal behaviors; the other six range from 3 (misinformation) to 54 (cybercrime), and the multimodal set of 110 contains no copyright rows at all.

The reason is structural rather than an oversight. A multimodal behavior is an image plus a request that references that image, and it is graded by feeding the classifier a RedactedImageDescription — a written description of the image with the harmful specifics removed — as context. That machinery answers "did the model do the harmful thing this picture makes possible?". Copyright asks a different question: "did this exact text come out?". There is no image-mediated version of verbatim regurgitation that would still be a language-model test — a photograph of a book page turns the task into OCR, which measures transcription, not memorisation, and grading it would require shipping the page. The two designs do not compose.

The plumbing agrees. Copyright grading is dispatched on the hash_check tag, and no row in the multimodal CSV carries any tag at all. There is nothing for the hashing path to pick up even in principle.

What to watch for here

Copyright is best understood as a memorisation probe wearing a red-teaming costume. Read that way it is a good instrument: it is cheap, it needs no GPU judge, its ground truth is a hash rather than a 13B model's opinion, and it will not drift when someone swaps the classifier. It is also the only slice of the benchmark whose score you can compare across papers without worrying about grader versions.

Read it as a safety metric and it will mislead you in three specific ways. A near-zero column is not evidence of alignment — it is consistent with a small model, a short generation budget, or a model that complied enthusiastically and got the words wrong. A rising number across a model family is not a regression in safety training; it is more likely a bigger model with more of the corpus in its weights. And because over-refusal is not measured anywhere in HarmBench, a model that refuses every copyright request scores a perfect 0 here and is indistinguishable from one that has never seen the works — the benchmark has no way to tell you which, and no benign control set that would.

If you are running the pipeline yourself, three concrete cautions. Do not change the 512-token cap without saying so, because the book windows are sized against it. Do not average copyright into a single headline ASR without a footnote. And do not read the near-zero gradient-attack cells as "GCG is defeated here" — the more accurate statement is that GCG is answering a question this metric does not ask. The one defense result worth noting is that R2D2, which drops GCG from 69.5 to 5.5 on all behaviors, does essentially nothing for copyright: adversarial training against a gradient adversary cannot un-memorise a text.
